# Provenance

This dataset is assembled by Kenta Kasai. Original construction and software
attributions are retained in README.md. In particular, the public minimal-twist
seed is attributed to Koki Okada, and the deterministic `scripts/zsnf.py` is
preserved byte-for-byte from the seed's supporting implementation (SHA-256
`c340546b87f403064f8c77036c2c48178da0d96b69ca1f852f71c99bbe41ebfa`).
No new blanket license is asserted for previously supplied third-party material.

Evidence files are frozen records. Hashes and archived exact-distance claims
do not substitute for replaying complete exhaustive-search receipts. The public
matrix schema and physical verifier expose the precise objects being cited.
